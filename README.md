# InvestMAC - Analizador Financiero

App de análisis técnico y fundamental con método AndyStopLoss.

## Características
- Modo AndyStopLoss (RSI + ASL21 + Soportes/Resistencias)
- Modo Completo (Técnico + Chartismo + Fundamental)
- Datos de criptomonedas en tiempo real desde Binance
- Alerta para TradingView

## Instalación local
```bash
pip install -r requirements.txt
streamlit run app_grafica.py
